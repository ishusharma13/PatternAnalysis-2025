# MambaIRv2 Colorization — Ishu Sharma

This project aims to convert grayscale images into realistic color images by fine-tuning a pretrained state-space model (MambaIRv2).

---

## Features Implemented So Far
- Paired grayscale → color dataset loader
- Simplified MambaColorizer model wrapper
- Basic training loop with checkpoint saving
- Inference script to colorize individual images
